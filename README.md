# Abliterato releases

Binary releases of [Abliterato](https://abliterato.com), the uncensored, offline image generator for Apple silicon Macs.

- Latest DMG: https://github.com/anthonykrivonos/abliterato-releases/releases/latest/download/Abliterato.dmg
- Requirements: Apple silicon, macOS 14 or later, 32 GB unified memory recommended, 45 GB free disk.
- First launch downloads about 35 GB of model weights from Hugging Face. That is the only time the app uses the network.

The source lives in a private repository. Each release lists its SHA-256 so you can verify the download.
